## Setup

  ### Prerequisites
  - Node.js 18+ (or newer)
  - npm

  ### Step 1: Install dependencies
  ```bash
    npm i
  ```
  
  ### Step 2: Build static HTML
  ```bash
    npm run build
  ```
  
  ### To start development server
  ```bash
    npm run dev
  ```
